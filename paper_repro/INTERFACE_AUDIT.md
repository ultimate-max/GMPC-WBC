# 接口力与 ADMM 更新核对

依据：[论文 III-A、III-B 和算法 1](https://arxiv.org/html/2403.11742v3)。以下矩阵形式为本工程的独立推导，用于明确论文简写中未展开的接口方向。

## 1. 接口力消元：使用有符号约束

将三个子系统的世界坐标速度堆叠为 v，M 为分块对角质量矩阵，g 为驱动力、接触力与负偏置之和。令 J=[I6,0] 提取共同连接点的世界坐标 twist。约束矩阵采用独立的两条边：

```
C = [J, -J,  0;
     J,  0, -J]
v_free = v + dt M^{-1} g
v_next = v_free + M^{-1} C^T p
C v_next = 0
p = -(C M^{-1} C^T)^{-1} C v_free
```

p 是接口冲量，不是直接以牛顿计的力。各子系统接口广义冲量来自 C^T p，其基座分量之和严格为零。不能把所有 J 同号叠加后直接套论文公式（8）；那会丢失作用力与反作用力的方向。使用两条独立边也避免三条完整图约束的线性相关导致求逆奇异；ADMM 残差可以继续采用三条边。

把每个 M_i 分为 `[A_i,B_i; B_i^T,D_i]`，消去关节加速度：

```
H_i = A_i - B_i D_i^{-1} B_i^T
b_i = g_base_i - B_i D_i^{-1} g_joint_i
w_i = H_i v_base_i + dt b_i
v_base_next = (sum H_i)^{-1} sum w_i
F_i dt = H_i v_base_next - w_i
```

这正是默认 `coupling=1` 的 Schur 消元。`verify_interfaces.py` 在 24 组基座姿态、速度和控制量均不一致的状态下，将生成函数与独立 Pinocchio 数值 KKT 解比较，而不是只在静止或接口已一致时比较。最大速度差约 5e-13，接口速度约束误差与接口净冲量均约 1e-15。因此此次没有证据支持把原接口消元整体换号。

但每个局部优化调用采用自己的新变量和其他子系统的旧变量。不同局部调用算出的 F_i 来自不同的联合状态，不能据此保证这些 F_i 在当前有限迭代后仍严格相抵。新增 `net_interface_wrench_max` 和原有完整动力学缺陷都用于检查这一点，不能只看速度一致性残差。

## 2. 对偶符号与两两残差

从论文公式（2）的 `+ y^T r` 出发，取 d=y/rho，则平方项必须写成 `||r+d||²`；更新是 `d_next=d+r_next`。若改用 `||r-d||²`，就必须同时改为 `d_next=d-r_next`。论文公式（12）的减号与算法 1 的加法若被直接用于同一 r、同一 d，会有符号约定歧义。本工程明确使用前一套自洽约定，不机械照抄减号。

论文采用 r_ij=v_i-v_j。本次改为反对称边乘子 d_ij=-d_ji 的聚合实现，三子系统时：

```
d_i = (d_ij + d_ik)/2
target_i = (v_j_previous + v_k_previous)/2 - d_i
d_i_next = d_i + eta_d * (v_i_new - (v_j_new+v_k_new)/2)
         = d_i + eta_d * 1.5 * (v_i_new - mean(v_new))
```

两个邻居的平方项可合并为一个平方项加与本地变量无关的常数；聚合平方项权重是单条边权重的两倍。本工程运行时 rho 指聚合权重。测试同时检查显式三条边与聚合实现的一致性，误差约 1.6e-15；一致符号的标量共识例子收敛到解析均值，反向符号则发散。

局部旧轨迹保留各自的基座副本。`Map` 是从含局部副本的全局迭代中提取对应变量，不在每次迭代之前无条件覆盖为算术平均。旧的中心平均形式保留为 `--admm-form consensus` 诊断选项。

## 3. 确定的实现错误：不存在的终端约束也在积累乘子

正式代价只在 k=0,...,N-1 有一致性罚项，但旧实现对 k=N 也执行了对偶更新，并在热启动移位时不断复制末端乘子。这个没有对应罚项的乘子会累积，再被移入有效的预测区间。

修复为：

- k=N 的一致性乘子始终为零，不执行对偶更新。
- 每周期移位两个节点；有前驱运行节点的乘子正常移位，新进入的两个运行节点及终端乘子初始化为零。
- 原始状态/控制的尾部保持与对偶尾部初始化是两件事，不能共享同一个“末值保持”规则。

`--self-test 1` 直接调用 C++ 的实际 `shift()` 和控制器更新逻辑，检查节点标签移位和终端乘子为零。它不是另写一份模拟实现来验证自身。

这一错误确实需要修复，但**它不是已被证明的唯一失败原因**：修复后无阻尼、每周期一次更新的版本仍未通过闭环。当前边乘子版本在 0.58 s 出现 `ACADOS_MINSTEP`（QP 第 33 次迭代），负对照记录于 `audited_single_step.log`。旧版约 0.66 s 失败，不应被概括为“只修这一行就好了”。

## 4. 有限步 Jacobi 更新的共同方向过冲

一个三子系统标量例子能解释速度一致性指标的盲区：每个局部解使用其余两个系统旧输入，并选择自己的新输入，使本地预测速度为零。若旧输入共同偏离目标 e，则三个新输入都变成 -2e。各局部预测速度彼此相等，接口残差仍为零，但实际联合输入的误差翻倍。

独立测试包含这个反例。它说明“接口残差小”不是充分的完整动力学可行性证据；它不单独证明机器人故障的全部原因。机器人对照中，直接完整步长更新失败；仅禁用对偶、并对原始变量阻尼时可以保持有限时域稳定。最终保留非零对偶更新，采用下面明确记录的稳定配置。

## 5. 当前稳定配置及边界

`--profile stable`：每周期 10 次并行协调，每个局部调用仍为一次 SQP-RTI；原始变量更新步长 0.2，对偶更新步长 0.05，聚合 rho=200、sigma=100。保持 50 个节点、10 ms 预测步长、20 ms 仿真控制周期、原有硬足高约束和接触模型。没有集中式求解器回退，没有关闭 ADMM 对偶，没有额外外力或固定基座。

`--profile single_step`：保留无阻尼原始/对偶完整更新、每周期一次协调，用于验证论文形式的差距。这一配置尚未验证成功。

因此，稳定配置是经过阻尼的有限迭代 ADMM 实现，**不能宣称已经复现论文单步 RTI 的加速或收敛结论**。仿真通过也不构成闭环稳定性定理；当前只报告明确测试的任务和时间范围。
