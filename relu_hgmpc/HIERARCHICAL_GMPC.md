# 一阶层级 GMPC（2026-11-10）

当前入口是 `run_hierarchical_gmpc.py`，控制器为 `hierarchical_gmpc.py`。它在已核对的一阶 `PaperGMPC` 上实行两个词典序层级。旧 `controller.py` 中早期 ReLU-QP 两层原型、`split_gmpc.py` 中加权分布式版本、此处的 OSQP 层级版本是不同实现，不能混用结果。

## 层级定义

物理可行域 K 包含原有动力学、固定四足接触、接口一致性、摩擦、力矩及其变化、关节位置/速度和机身偏移约束。

1. 主任务：在 K 内最小化整个预测域的 `J1 = ||C x + d||²`。C,d 包含原有 SE(3) 位姿误差和误差变化率，保留原物理权重和三倍终端权重。
2. 次任务：在 K 内及 `C x2 = C x1` 条件下，优化机身姿态、关节构型/速度、输入与辅助力正则、输入变化。原有 `1e-9 I` 数值正则只放在第二层。

第一层中位置、姿态和误差变化率仍以权重协调，并非三者之间各设一个严格层级。物理约束是硬约束，不能为完成跟踪而违反。

在固定局部凸 QP 上，如果第一层精确求解，则所有最优解具有相同的 Cx：否则两个不同输出的最优解中点会给出更小的严格凸残差范数。因此锁定 Cx 保留整个主任务最优解集合，第二层只在该集合内作选择。有限容差下实际锁定的是第一层已验收的预测输出。此结论不代表非线性真实系统的全局任务保持或闭环稳定性。

## 两次等式参数化

先复用 `ContactReduction`，得到 `x = T z + c`：原420变量降为180个关节力矩坐标；两层共用一次物理消元，原1040行不等式全部保留。

完整任务输出有120行，其中60行位姿、60行误差变化率。对于初始状态相同的两组预测，有

```
delta(phi_1) = 0
delta(phi_(i+1)) = delta(phi_i) + dt * delta(phidot_i)
```

因此保留60行误差变化率等式即可保持全部120行输出。实现按物理权重构造精确提升矩阵 L，逐周期核对 `C = L D`，没有按数值大小截断任务方向。

进一步对 `(D T).T` 作完整 QR，得到其零空间基 Z：

```
z2 = z1 + Z eta,  (D T) Z = 0
```

第二层使用120个 eta 变量、1040行原不等式，任务锁定自动成立。输入变化界限、摩擦等所有约束仍作用于恢复的物理输入。若任务映射失去满行秩，则明确报错，不静默丢弃任务方向或降低优先级。零空间基随状态更新，不能缓存旧基作为新问题的精确基。

对第二层先由 QR 恢复任务等式乘子，再恢复接触/接口等式乘子。两层均在原420维坐标检查原始、驻点及法锥相对残差，门槛同为2e-7；额外检查全部120行任务残差保持，门槛也是2e-7。所有构造、投影、恢复和检查均计时。QP失败时明确停止，不退回加权求解器。

## 使用

从 `/home/ganhe/project/b2z1_mpc` 执行：

```bash
source relu_hgmpc/env.sh
python relu_hgmpc/test_hierarchical_gmpc.py
python relu_hgmpc/run_hierarchical_gmpc.py --duration 12 --scale 1 --name hierarchy_demo
python relu_hgmpc/run_hierarchical_gmpc.py --controller weighted --duration 12 --scale 1 --name weighted_demo
```

`--locks nullspace` 是默认正式实现；`--locks all` 和 `--locks rate` 保留显式120行及60行等式的诊断版本。`--fresh` 关闭求解器工作区复用。当前验证的是CPU集中式OSQP，不代表ReLU-QP或子系统ADMM已接入这套新层级。

测试核对旧加权 H/g/A/l/u 逐位不变、主次代价之和一致、两层KKT、120行任务保持、次层代价改善、改变次任务偏好不改变第一层，以及显式锁定和零空间参数化的次层最优代价一致。

## 结果与局限

逐周期数据位于 `results/hierarchical_gmpc/`，汇总由 `report_hierarchical_gmpc.py` 生成。原加权四组加速实验保留在 `results/osqp_acceleration/`，其2.16–3.09倍加速不能移用为本层级控制器的加速倍率。

层级优先保障预测跟踪，可能减少次任务平滑的可用余量；是否降低实际关节波动需要实测，不能从“层级”二字推导。实验保持N=10、dt=30ms、反馈20ms，使用MuJoCo真值和共同低层控制，未注入计算延迟。物理仿真闭环跑通不等于满足50Hz实时执行，也不等于硬件验证。只验证固定四足支撑，尚无接触切换或奇异构型回退策略。
