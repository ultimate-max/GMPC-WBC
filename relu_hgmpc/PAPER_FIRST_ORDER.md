# 一阶几何误差动力学补全与冻结版本对照

2026-11-10。对应实现 `paper_gmpc.py`；原 `split_gmpc.py` 未改动。

## 原文依据及对上一轮解释的纠正

主要依据工作区已保存的《Hierarchical Geometric Model Predictive Tracking Control for Redundant Robot Manipulators in Task Space》全文，III-A/B 节，公式 (13)–(18)、Assumption 1、(22)–(24)。该版本明确：每个采样时刻评估 H、F、b 与冗余投影，并在该次预测域中冻结；参考速度沿预测域变化。因此，上一轮把“没有完整的动力学配置/速度 Taylor 导数”描述成偏离这篇论文的必要缺项，不够准确。论文要求的是包含 HV、雅可比变化和冗余速度项的任务空间名义模型，不是完整多次 SQP。

另一篇 [An Error-State Model Predictive Control on Connected Matrix Lie Groups for Legged Robot Control](https://arxiv.org/html/2203.08728) 的 (15) 给出相同形式的几何误差传播。它的 (16)–(18) 是常惯量单刚体的速度线性化，不能直接代替四足＋机械臂的构型相关多体动力学。

本轮补全连续时间一阶几何/任务速度预测，末端任务状态使用论文的前向 Euler。保留当前加权多任务、四足接触和底盘—臂接口优化；不是复现原文 7 自由度机械臂的严格两层优先级、终端集合或稳定性证明。关节/接触可行性和静止底盘辅助预测继续采用原工程的一阶半隐式次序。正式对照文件以 `aligned_` 开头；此前未对齐末端离散公式的实验仅留作排查记录，不进入主结果。

## 1. 几何误差传播

令 E=T_d^{-1}T，phi=Log(E)^vee，V 为工具坐标的体速度。精确关系为

\[
\dot\phi=J_r(\phi)^{-1}(V-\mathrm{Ad}_{E^{-1}}V_d).
\]

在 E=I、V=Vd 周围保留一阶项：

\[
\dot\phi=-\mathrm{ad}_{V_d}\phi+V-V_d
+O(\|\phi\|^2+\|\phi\|\|V-V_d\|).
\]

跟踪代价使用 y=[phi; phi_dot]；输出矩阵为

\[
C_{out,i}=\begin{bmatrix}I&0\\-\mathrm{ad}_{V_{d,i}}&I\end{bmatrix},
\quad d_i=\begin{bmatrix}0\\V_{d,i}\end{bmatrix},
\quad C_{out,i}^{-1}=\begin{bmatrix}I&0\\\mathrm{ad}_{V_{d,i}}&I\end{bmatrix}.
\]

代码全部采用 Pinocchio 的 [linear; angular] 顺序，而原文为 [angular; linear]；ad 直接调用同一顺序的 `pin.Motion(...).action`。不能混用论文中的块位置。

## 2. 包含冗余速度的任务动力学

对一个子系统记 M a + C v + g = B_u u。C 是 Pinocchio 科氏矩阵，g 是重力广义力。B_u 包含关节力矩、接触力和内部接口力的作用映射。设

\[
\bar J=M^{-1}J^T(JM^{-1}J^T)^{-1},\quad
v_N=v-\bar J Jv,\quad K=\dot J-JM^{-1}C.
\]

则在当前测量点

\[
H=K\bar J,\quad F=JM^{-1}B_u,\quad
b=Kv_N-JM^{-1}g,
\qquad \dot V=HV+Fu+b.
\]

相较旧版本，这里保留了 HV、Jdot、Cv 和测量冗余速度 vN 对任务加速度的贡献。H/F/b 每周期更新一次，预测域内保持不变，符合原文 Assumption 1。末端任务建立在现有“底盘＋机械臂”虚拟子系统上；其质量矩阵沿用已有根节点质量拆分，输入含接口力，并通过另一个子系统的共识约束耦合。它是对既有分解工程的扩展，不是把固定基论文当成原样适用于浮动基系统。

关节与接触可行性预测同时保留冻结 C 下的速度耦合：

\[
a_i=G u_i+a_0+A_v(v_i-v_0),\quad
G=M^{-1}B_u,\quad a_0=-M^{-1}h(q_0,v_0),\quad A_v=-M^{-1}C(q_0,v_0).
\]

第一节点 v_i=v0，故恢复与原始非线性当前点相同的加速度；后续节点使用仿射预测。底盘静止参考 Vd=0，其一阶误差关系为 phi_b_dot=v_b；姿态约束和代价均按该关系预测。末端独立任务状态按论文的固定 H/F/b 传播，冗余速度冻结是名义预测假设，不能解释为实际冗余速度不变。每周期由真实 q/v 重置任务状态与系数。

这仍不是完整的 a(q,v,u) 对全部变量的 Taylor 展开：没有把配置依赖全部导数加入预测，也不在预测节点更新 M/J/C。大构型变化、奇异点或接触切换需要另行验证。

## 3. 离散化与预测

在一周期中预先计算 A_V=I+dt H、B_V=dt F、b_V=dt b。按论文 (22)–(24) 的前向 Euler，在每节点从同一个旧状态同时更新

\[
V_{i+1}=A_V V_i+B_Vu_i+b_V,
\]
\[
\phi_{i+1}=(I-dt\,\mathrm{ad}_{V_{d,i}})\phi_i
+dt(V_i-V_{d,i}).
\]

下一节点的 phi_dot 由 C_out,i+1 和 d_i+1 计算。测试独立构造论文 12 维块矩阵及 C_i 坐标变换，核对所有预测节点。不能在此式中混用 V_i+1 和 Vd_i，否则变化参考会引入额外的时刻错位。所有量对控制序列仍为仿射关系，因此优化仍是凸 QP；无需非线性求解器或多次 SQP。

## 4. 可以预计算或复用的内容

### 已知参考：可提前计算

- 参考位姿 Td(t)、体速度 Vd(t)。
- ad(Vd,i)、I−dt ad(Vd,i)，以及输出矩阵 C_out,i、d_i、C_out,i 的解析逆。代码实际缓存需要用到的前两块，输出运算直接使用 ad 块，避免存整块零/单位矩阵。
- 只依赖参考和 dt 的运算，可在参考命令不变时复用。本实验在已知整条参考轨迹上预计算；启动成本单独测量并摊销，未隐藏。

### 结构常量：跨周期复用

- 输入缩放、关节选择矩阵、逐节点输入选择矩阵。
- 当前固定接触模式/摩擦参数下的摩擦锥矩阵结构。
- 单位块、零块及预测维度。代码缓存前述选择矩阵和摩擦模板。

### 当前状态系数：只在同一预测域内复用

- M、C、g、J、Jdot、Jbar、vN、H、F、b。
- A_V、B_V、b_V、关节 A_v，以及输入到加速度的映射。
- 这些量按测量状态每周期重新计算；本轮不采用近似跨周期冻结。

### 不应无条件跨周期复用

- 完整预测映射、QP Hessian、约束数值矩阵及它们的数值分解。
- 构型、速度、接触、载荷或权重变化会改变它们。稀疏结构缓存与数值因子缓存是不同的事情。

参考缓存只适用于同一规定参考。在线参考改变后必须重建对应缓存；接触模式/摩擦参数改变后必须重建结构缓存。本轮固定四足站立，没有实现接触模式管理。

### 后续可做、但本轮尚未兑现为加速的复用

- 同周期的 M 分解可一次完成，批量求解 M^{-1}B、M^{-1}C、M^{-1}J^T、M^{-1}g；当前这些小矩阵求解仍有重复调用，不能把潜在收益算入本轮成绩。
- 已知参考的误差传播积 Phi_phi(i,j)=prod(I−dt ad(Vd)) 可预计算；但与 H/F 组合后的完整控制预测矩阵仍依赖当前状态。
- 固定接触和预测维度下，可预分配 QP 稀疏结构、复用求解器对象和符号分析；当前基线每周期新建 OSQP 对象并 setup。数值矩阵改变时仍需更新/重新数值分解，不能直接沿用旧数值因子并声称解的是同一 QP。
- 接触/接口等式消元后有望缩小数值分解规模；应保留可行性和残差核对，再测包含构造的总耗时。这不是仅缓存 ad 矩阵可以替代的工作。

## 5. 对照协议

五个版本：frozen 原版；frozen_cached 原版＋相同参考缓存；geometry_cached 只改几何误差传播，保持原冻结加速度；paper 补全任务速度项和冻结 C 的仿射关节预测；paper_cached 同一 paper 模型＋精确缓存。

模型/离散预测方程是实验自变量。所有版本保持相同机器人与安装、参考轨迹、420 个优化变量、同一类别/数值界限的物理约束、10×30 ms 预测、20 ms 控制、代价权重和终端倍率、同一 OSQP 后端和 2e-7 共同原始 QP 相对残差门槛。预测映射变化会相应改变 QP 矩阵；不能称不同模型的 H/A 数值完全相同。

每种版本 12 s、600 周期，顺序及逆序各一次；单进程顺序运行，不并行测时。缓存前后相同模型应给出相同结果，单独检查。补充双幅参考下 frozen_cached / paper_cached 的对照。

原参考是平滑起步的 0.2 Hz 附近六维运动；SE(3) 切向平移分量系数为 0.025 sin(p)、0.015(1−cos(p))、0.010 sin(p) 米，旋转分量为 0.06 sin(p)、0.04 sin(0.7p)、0.08 sin(p) 弧度。双幅实验将这六个分量统一乘 2；并非大姿态、奇异构型或行走接触切换测试。

总反馈时间从读取 MuJoCo 真值、计算原生模型开始，包含矩阵构造、QP 准备与求解、命令恢复和运行诊断；不包含物理仿真推进与绘图。另外报告原 controller_ms 口径、构造时间、P95/P99、启动预计算和摊销总时间。此为仿真控制性能测试，未把实际计算延迟注入仿真；不能据此宣称满足 20 ms 实时周期。

## 6. 验证

`test_paper_gmpc.py` 验证 C v+g=h，J vN=0，任务模型与 J a+Jdot v 在当前点的一致性，Jdot 的独立中心差分，以及精确 log 误差向量场与一阶模型的二阶余项。误差量减半时余项约缩为四分之一。

同时核对论文 (23)–(24) 离散输出变换、缓存前后 QP 数值、共同残差门槛、第一节点动力学和足端接触。测试输出为 `results/paper_gmpc/verification.json`。闭环结果及自动生成的汇总另见 `results/paper_gmpc/RESULTS.md`。

复现：加载 `relu_hgmpc/env.sh`，运行 `test_paper_gmpc.py`，随后执行 `benchmark_paper_gmpc.sh`。生产基线 `split_gmpc.py` 未修改，新增模型位于独立类中。
