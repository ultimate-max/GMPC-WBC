# 同一 GMPC 的 OSQP 持久化与精确接触消元

2026-11-10。实现：`osqp_acceleration.py`。原 `paper_gmpc.py`、`split_gmpc.py` 和机器人模型不变。

## 保持的优化问题

继续使用已对齐论文的末端一阶几何/任务速度模型，以及现有浮动底盘、四足接触、接口力和加权任务。N=10、预测步长30 ms、控制间隔20 ms、420个原始变量。参考缓存、代价权重、末端倍率、摩擦锥、关节/力矩/速度/位姿/力矩变化界限、初值和低层控制均保持不变。

四个实验版本：baseline 每周期重新 setup 完整 OSQP；reuse 持久化完整 OSQP；eliminate 精确消元后每周期 setup；combined 消元后持久化。全部使用同一 Pinocchio/MuJoCo 和 CPU OSQP；没有加入 GPU 或换求解器。

## 1. 结构复用不是冻结数值矩阵

[OSQP 官方 Python 文档](https://osqp.org/docs/interfaces/python.html) 支持在稀疏结构固定时更新 P/A 的数值。实现保留工作区、CSC 索引和已建立的结构，每周期更新 Hessian、约束矩阵、线性代价和边界。数值矩阵发生变化时仍进行数值分解，不把旧因子当作新问题的精确解。

初始静止状态的零元素不保证将来仍为零。实现逐周期检查精确非零结构；出现新非零项时扩大结构并重新 setup，记录次数；不设截断阈值，也不丢弃小非零项。维度变化同样会重建。当前只验证固定四足接触。

所有方法使用原来的控制序列平移热启动；完整 primal warm start 经消元后取自由力矩坐标。新持久化实现与原 fresh 方法一样，开始每周期时 dual warm start 为零。OSQP 工作区中的自适应 rho/内部缩放状态可随持久化保留，因此实测属于工作区持久化的总效果，不能把全部迭代变化都归因于符号分解复用。每周期恢复默认内部容差，若原问题残差未达标则收紧内部容差继续求解。

## 2. 用等式恢复接触力和接口力

原问题是

\[
\min_x\;\tfrac12x^THx+g^Tx,\qquad E x=b,\quad l_I\le A_Ix\le u_I.
\]

每节点保留18个按原比例缩放的物理关节力矩 z；另外24个量 w 是12个足端接触力、两组6维接口力。对应的24个等式为12维足端加速度约束、6维底盘速度一致性、6维接口力平衡。

按节点排列后，令 E_F/E_D 对应自由/依赖坐标，则

\[
w=E_D^{-1}(b-E_Fz),\quad x=Tz+c.
\]

E_D 是24×24分块的下三角矩阵，按时间顺序逐块求解。本实现直接使用当前 QP 的实际等式，因此包含新模型中的冻结 C 速度耦合，未换成旧冻结 h 的物理近似。各周期重新计算这些数值块。

变换后的问题为

\[
H_r=T^THT,\quad g_r=T^T(Hc+g),\quad A_r=A_IT,
\]
\[
l_r=l_I-A_Ic,\qquad u_r=u_I-A_Ic.
\]

目标只差与 z 无关的常数。变量由420降为180；240个等式由参数化精确满足；1040行不等式全部保留。没有移除摩擦锥、关节界限或力矩变化约束。

## 3. 恢复原始乘子与统一残差

消元后的约束乘子保留为 y_I。用依赖坐标的原始 stationarity 方程恢复

\[
E_D^Ty_E=-(Hx+g+A_I^Ty_I)_D.
\]

这可以使用消元时的分块 LU，逆时间顺序求解。实际代码还处理了等式和 OSQP 约束的行缩放。

最终统一在原420维问题检查 primal、dual 和 normal-cone 相对残差，三者都必须 <=2e-7，不能仅检查180维问题的内部 residual。原工程的原始残差定义不变。每一次额外求解、恢复和残差计算都计时。

## 4. 验证与有限精度边界

测试检查任意自由输入的 E T=0、E c=b、目标函数等价和全部不等式变换；用原完整 QP 的高精度解独立核对消元解；显式测试零元素变成非零元素时的重建及后续复用。

原 QP 较病态，满足同一个相对残差门槛并不意味着力矩序列逐位相同。等价性测试采用2e-11门槛来降低这种影响；正式闭环仍使用原2e-7门槛。闭环中若跟踪误差变化，不能归因于物理模型或代价函数变了，应结合有限迭代/内部缩放和条件数解释。固定状态的有限精度审计单独保存。

## 5. 计时协议与复现

普通幅度与双幅轨迹，每种方法各两次12 s闭环；按顺序/逆序串行运行。所有版本都使用之前验证的参考/结构常量缓存。

总反馈时间从 MuJoCo 真值读取开始，包含原生模型、所有预测矩阵构造、完整 QP 组装、消元、OSQP 初始化或更新、迭代、乘子/控制恢复和原问题残差及物理诊断。启动参考缓存单独统计并摊销；仿真推进不计入。没有将计算延迟注入仿真，不以仿真跑通宣称20 ms实时达标。

当前保留完整420维矩阵供共同残差核对，再进行精确消元；尚未把所有模型构造直接写到180维坐标。这样可以明确验证等价性，其构造和验证开销均包含在本轮结果里。
